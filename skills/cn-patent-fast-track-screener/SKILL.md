# 加快程序初筛

知产实务工作台 · 实务技能 | `cn-patent-fast-track-screener`

本 Skill 用于在中国发明专利“申请前”及“审查中”早期，帮助申请人或代理师判断技术方案是否可能适用专利加速通道：
1. **申请前·专利预审（知识产权保护中心通道）**：根据申请人所在地（省/市/特殊区域）与技术方案的 4 位 IPC 小类，初筛可申请备案与预审的保护中心。
2. **审查中·优先审查（国家知识产权局优审通道）**：根据完整 IPC 组/小组号（如 `G06N 3/08`）与法定产业分类目录进行精确比对，并核对 6 大法定优先审查情形。
3. **IPC 分类号规范化与初筛**：由 AI Agent 直接阅读技术交底书推断候选 IPC，再由本地 Python 脚本完成标准校验与双轨初筛，不依赖任何第三方商业 API。

## 快速工作流程（3 步走）

```
[步骤 1: Agent 推断 IPC 与主体核验]
用户提供技术方案描述 + 申请主体所在地（省/市/特殊区域）+ 申请主体性质
    │
    ├─> 【申请主体类型提醒】
    │   多数知识产权保护中心的预审备案主体必须为在服务区域内注册的企事业单位、
    │   高校或科研院所，个人申请人通常无法办理预审备案（以当地保护中心规定为准）；
    │   个人申请人仍可在符合《专利优先审查管理办法》情形时向国家知识产权局申请优先审查。
    │
    ▼
Agent 分析核心发明点，推断出 1 个主要 IPC 分类号（尽量推到组/小组号，如 G06N 3/08）
以及 0~2 个次要 IPC 分类号（如 G06V 10/40）
    │
    ▼
[步骤 2: 运行本地脚本初筛]
运行 python scripts/screen.py -p <省> -c <市> --primary-ipc <主要IPC> --secondary-ipc <次要IPC1> --secondary-ipc <次要IPC2>
    │
    ▼
[步骤 3: 综合解读与合规建议]
输出总判断、预审受理中心及触发源标注（主要/次要）、优审官方目录出处、后续行动建议及法定免责声明
```

## 常用脚本与命令

本 Skill 的所有脚本均基于 Python 标准库开发，数据随目录自带打包，支持在任意目录独立运行：

### 1. 综合一键初筛（预审 + 优审 + 术语定义）
```bash
# 传入 1 个主要 IPC 和多个次要 IPC（注意：多个次要 IPC 需重复指定 --secondary-ipc，每次传入一个）
python scripts/screen.py \
  --province "浙江省" \
  --city "杭州市" \
  --primary-ipc "G06N 3/08" \
  --secondary-ipc "G06V 10/40" \
  --secondary-ipc "B60W 30/00"
```
**输出说明**：
- `status`: `accelerated_matched`（至少一路命中）、`not_matched`（两路均未命中）、`unknown`（未得到有效 IPC）。
- `accelerated_paths`: 命中通道清单（`["preexam", "priority_review"]`）。
- `candidate_centers`: 所在地的候选保护中心列表，包含每个中心命中的小类及触发来源（`matched_ipc_details` 明确标注 `source: "primary"` 或 `"secondary"` 及具体输入分类号）。
- `warnings`: 当出现“主要 IPC 未命中但仅次要 IPC 命中”时，自动附带专项复核警示。
- `priority_review.matched_sources`: 命中优审体系的原表出处及技术分支。

### 2. 单独核对预审范围（知识产权保护中心）
```bash
# 单独核对指定省市与 IPC
python scripts/match_preexam.py -p "广东省" -c "深圳市" --primary-ipc "H01M 10/0525"

# 支持多个次要 IPC（重复使用 --secondary-ipc）
python scripts/match_preexam.py -p "浙江省" -c "杭州市" \
  --primary-ipc "A01B 1/00" \
  --secondary-ipc "G06N 3/08" \
  --secondary-ipc "G06V 10/40"

# 支持特殊保护区域（如北京市中关村示范区、天津市滨海新区）
python scripts/match_preexam.py -p "北京市" -s "中关村" -i "G06F 30/27"
```

### 3. 单独核对优先审查（国家知识产权局）
```bash
# 精确核对完整分类号
python scripts/check_priority_review.py -i "E02D 17/20"

# 检索特定 IPC 在优审体系中对应的技术分支与规则出处
python scripts/check_priority_review.py --search "G06N 3/08"

# 查看《专利优先审查管理办法》全部 6 种法定情形与所需证据指引
python scripts/check_priority_review.py --list-conditions
```

### 4. IPC 代码规范化校验与定义查询
```bash
python scripts/normalize_ipc.py G06F30/27 H01M10/0525 --with-definitions
```

## 判定规则核心原则（防坑要点）

1. **预审 vs 优审的粒度差异**：
   - **预审**看 **4 位小类（subclass）**，如 `G06F`、`H01M`。只要保护中心受理该小类即算分类范围命中。
   - **优审**严格要求 **完整 IPC 组/小组号（group/subgroup）**，如 `G06F 30/27`、`H01M 10/0525`。绝对不能用 4 位小类推定优审命中！
2. **次要 IPC 预审规则与仅次要命中的风险**：
   - 次要 IPC 的 4 位小类可以参与预审命中判定（原系统避免“只按主分类命中”）。
   - **风险警告**：当“主要 IPC 小类未命中、仅次要 IPC 命中”时，系统将发出提示：“主要 IPC 小类未落入候选保护中心预审范围，仅次要 IPC 命中；保护中心是否接受以其分类审核为准，建议复核主要分类号是否准确。”在实务申报中，保护中心若判定方案主要发明点属于未受理事权，可能直接退案。
3. **两套通道非互斥**：
   - 预审是在申请前向保护中心申报；优审是在申请进入实质审查后向国家知识产权局申请。
   - 即使预审未命中或最终未通过，不影响正常申请专利，进入实审后仍可按重点产业目录或实施事实证据申报优审。
4. **主要 IPC 与次要 IPC**：
   - 主要 IPC（1 个）代表最核心的发明构思，次要 IPC（最多 2 个）代表应用领域或配合结构。避免输入超过 3 个代码以防稀释重心。

## 输出话术规范与免责声明

在向用户汇报初筛结果时，请严格遵守以下表述准则：

- **禁止绝对化承诺**：严禁出现“一定能预审”、“预审已通过”、“保证快速授权”等误导性表述。
- **正面标准表述**：
  - 预审命中：“预审分类范围命中，申请主体（企业/高校/科研院所）完成所在地保护中心备案后可考虑申请预审。”
  - 仅次要命中：“候选保护中心受理次要分类号，但主要分类号未落入受理范围；审查时以保护中心对核心发明点的认定为准，建议重点复核主要分类号。”
  - 优审命中：“该完整分类号落入国家知识产权局《...》优审目录，可在进入实质审查后进一步评估优先审查。”
  - 两者均未命中：“技术方案未落入当前保护中心预审公布范围，也未直接命中官方优审分类目录。若方案符合已做好实施准备或地方重点扶持产业等法定情形，仍可考虑按事实证据申报优审。”
- **法定免责声明**：每次答复末尾必须附带：
  > **免责声明**：本分析仅供专利加快程序分类范围初筛参考，不代表保护中心或国家知识产权局一定受理，不构成对技术方案新颖性、创造性或授权前景的实质判断。正式申报前请以主管部门最新公布目录及个案审查意见为准。

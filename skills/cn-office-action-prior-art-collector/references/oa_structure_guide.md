# 中国专利审查意见通知书（OA）结构与解析规范

中国国家知识产权局（CNIPA）下发的审查意见通知书具有高度严格的标准版式。理解通知书的各个栏目对于准确提取对比文件和审查意见至关重要。

---

## 1. 通知书各栏目结构与关键标识

一份标准的审查意见通知书（通常为《第一次审查意见通知书》或《第N次审查意见通知书》）通常由以下部分组成：

```
+------------------------------------------------------------+
| 封面著录项：发文日、申请号、发文序号、申请人、发明创造名称 |
+------------------------------------------------------------+
| 栏目 1-4：说明书修改、权利要求修改、分案申请等常规审查事项 |
+------------------------------------------------------------+
| 栏目 5：对比文件引用栏（核心对比文件来源）                 |
|   "5. 本通知书是在进行了检索的情况下作出的。               |
|    本通知书引用下列对比文件(其编号在今后的审查过程中继续沿用): |
|    对比文件1：CN114528944A ...                             |
|    对比文件2：US20200234567A1 ...                          |
+------------------------------------------------------------+
| 栏目 6：审查的结论性意见（概述新颖性、创造性、充分公开等）  |
+------------------------------------------------------------+
| 正文详细意见段落：                                         |
|   "经审查，现提出以下审查意见："                           |
|   逐项针对具体权利要求和法条论述审查意见                   |
|   结尾："审查员姓名：XXX"                                  |
+------------------------------------------------------------+
| 附页：检索报告（非本次通知书直接引用的对比文件，须剔除）   |
+------------------------------------------------------------+
```

## 2. 关键提取规则与避坑要点

### 2.1 对比文件抽取边界（第 5 栏 vs. 检索报告）
- **核心原则**：对比文件列表**必须仅从“第 5 栏”**截取，严禁从末尾附带的“检索报告”中提取！
- **为什么**：“检索报告”中常列出审查员检索到的所有相关文献（包括大量仅代表技术背景的 A 类文献）。本次通知书真正据以驳回或提出质疑的对比文件，仅在第 5 栏明确列出。
- **剔除本案号码**：若第 5 栏中无意提及了本案申请号本身，必须将其排除，避免将本案误认作对比文件。

### 2.2 正文审查意见（Objections）与法条匹配
正文审查意见通常针对特定权利要求，依据《专利法》具体条款展开：
- **创造性**：引用《专利法》第 22 条第 3 款（`不具备创造性`、`突出的实质性特点和显著的进步`）。
- **新颖性**：引用《专利法》第 22 条第 2 款（`不具备新颖性`、`属于现有技术`）。
- **充分公开**：引用《专利法》第 26 条第 3 款（`说明书未充分公开`、`所属技术领域技术人员无法实现`）。
- **权利要求清楚与支持**：引用《专利法》第 26 条第 4 款（`权利要求书未以说明书为依据`、`不清楚`、`缺少必要技术特征`）。
- **单一性**：引用《专利法》第 31 条第 1 款（`缺乏单一性`、`不属于一个总的发明构思`）。

### 2.3 权利要求编号范围展开
审查员正文中常使用简写范围：
- `权利要求1-3` -> 展开为 `[1, 2, 3]`
- `权利要求1、2及4` -> 展开为 `[1, 2, 4]`
- `权利要求1至5` -> 展开为 `[1, 2, 3, 4, 5]`
规范化为标准整数数组，便于后续答复策略一一对应。

## 3. 自由资料文档模式（文献清单）
当用户上传技术交底书、文献清单、Excel 复制文本等非标准通知书文档时：
- 跳过著录项和正文法条提取；
- 使用收紧的正则表达式 `_PATENT_PREFIXED_RE` 从全文中召回专利文献号；
- 过滤无关数字串（如产品型号、年份数字等），按文本出现顺序去重，自动生成对比文件清单。

# 中国发明专利范本筛选 - 知名申请人与代理机构名单
# 格式：每行一个实体名称；# 开头为注释；## 小标题（Tier N）决定该段落的梯队分
# 用途：rank_template_candidates.py 解析本文件，把申请人/代理机构折算为范本质量分
# 解析规则：标题含"代理/事务所"归入代理机构表，含"公司/申请人"归入申请人表；
#          名称归一化后完全相等，或较短名称不少于 4 个字符时按包含匹配
# 分值：Tier 1 = 1.00，Tier 2 = 0.70，Tier 3 起按 0.30 递减且保底 0.40；
#      有名称但不在名单 = 0.30（中性、不视为低质）；名称为空 = 0.00 并标记 missing
# 边界：名单命中只表示"属于知名实体"，不代表对该机构撰写质量或法律结论的评价
#
# ============================ 代理机构名单口径 ============================
# 建档日期：2026-09-24；下一次复核：建议每年一季度榜单发布后
# Tier 1 = 体量与质量双重命中：发明专利代理量/授权量全国前列，且同时出现在
#          权威质量榜单（IPRDB 综合榜、Chambers 中国 IP、北京市专利代理师协会
#          5A 等级、IPRdaily×incoPat"全国执业百人以上代理机构"等）。
# Tier 2 = 单边强：体量居前但缺权威质量背书，或质量背书强但规模中等、地域集中。
# 已知偏差：只反映"公开榜单可见"的机构，服务体量小但质量高的精品所会缺席；
#          榜单本身存在数据公开周期误差与机构合并统计问题，不构成机构优劣的法律结论。
#
# 代理机构数据来源（2026-09-24 检索）：
#   1. 2025年发明授权量百强榜（专利茶馆/IPRDaily 口径，2026-01 发布）：集佳 14636 件第1、
#      广州三环 13882 件第2、北京品源 11926 件第3
#   2. 润桐 RainPat 专利指数：2025年1-9月中国发明申请量代理机构 TOP50（集佳/三环/品源前三）、
#      2025年第一季度发明申请量 TOP50（北京超凡宏宇、广州三环居前）、发明授权率 TOP50
#   3. IPRDB 专利代理机构综合排行榜（累计申请量 + 发明专利授权率 + 质量评分）
#   4. Chambers Greater China Region - Intellectual Property: Non-litigation (PRC Firms)
#   5. 北京市专利代理师协会 专利代理机构等级评定（5A/4A，含等级时效）
#   6. IPRdaily×incoPat"全国执业百人以上的专利代理机构发明授权排行榜"（13 家）
#   7. 国家知识产权局"全国知识产权服务品牌（培育）机构"名单
#   8. incoPat 2023 年发明专利代理量前 10（集佳/三环/品源/华进/清亦华/路浩/嘉权/康信/同立钧成/超凡）
#   9. 中华全国专利代理师协会"专利代理机构精准服务保障名单"（首批 986 家，过宽，仅作下限参考）
